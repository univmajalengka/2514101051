# Tugas Pertemuan 06-08: Hitung Diskon (PHP)

Mata kuliah: Pengembangan Aplikasi Berbasis Web

Program PHP dengan fungsi `hitungDiskon($totalBelanja)`:

| Total belanja        | Diskon |
|----------------------|--------|
| >= Rp. 100.000       | 10%    |
| Rp. 50.000 - 99.999  | 5%     |
| < Rp. 50.000         | 0%     |

Fungsi mengembalikan nilai diskon, lalu dipakai untuk menghitung total yang harus dibayar.

## Cara menjalankan
1. Letakkan folder di `htdocs` (XAMPP).
2. Jalankan Apache.
3. Buka `http://localhost/tugas-diskon/`.
